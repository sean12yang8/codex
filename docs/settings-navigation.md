# 系统设置导航（R11）

侧边栏移除独立的“同步中心”和“数据导入”，统一收进“系统设置”的标签页：

- 基础设置：保留汇率、审计与原有管理员设置。
- 数据导入：CSV 模板下载、导入 CSV、导入历史和批次详情。
- 同步中心：任务列表、任务创建、进度、重试、取消和任务详情。

进入系统设置默认打开基础设置。标签支持鼠标、左右方向键与 Home/End 切换，并适配手机屏幕。切换页面会卸载原标签内容，沿用既有任务持久化机制；任务继续由后台 Worker 执行。

本次仅调整界面导航；API、任务与导入批次、自动同步计划、权限及计算规则保持不变。普通成员仍能使用原本可访问的导入和同步功能；管理员设置继续由原管理员权限控制。
