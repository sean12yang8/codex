# 订阅消费统计与资源详情（R9）

数据总览原“最近数据导入”区域改为订阅消费统计。表格跟随总览日期、客户、租户和订阅筛选，提供搜索、分页、原币费用、ACR 试算、已核验 ACR、已采集订阅日及最近同步时间。历史归属按消费日分别列示。导入批次仍可从“数据导入”查看。

工作空间 → 资源详情，或订阅统计行的“查看资源”，可查看该订阅的资源级费用。支持客户、租户、订阅、UTC 日期、服务和资源搜索。资源表含名称、ARM Resource ID、资源组、资源类型、服务、原币费用、两种 ACR 口径及费用日期；“每日明细”列出日/服务费用、试算折扣、FX、当前折扣回推标记、待核实标记和来源版本时间。资源列表属于费用视图，可能包含已删除但仍有费用的资源。

## 来源与计算

- 使用现有租户服务主体的 Cost Management ActualCost Daily Query，按 ResourceId + ServiceName 分组；沿用分页、精度、限流退避和重试机制。没有 Resource ID 的费用保留为“未分配到资源的费用”。
- 资源查询按最多 7 个 UTC 日分区执行，每日原始快照和有效费用独立持久化。订阅服务日费用仍是总览权威汇总，资源数据不再加入总额。并发发布使用订阅锁；相同快照幂等；修订仅替换返回日。
- 资源费用沿用消费日归属、折扣版本、USD FX、基数核验和已获授权的待核实试算规则。原始金额不混币相加。未知日期或无记录金额保留为空。
- 金额/日期对齐检查比较资源快照与订阅汇总。不同采集时间、覆盖日期或上游调整可能产生差额；已对齐也不表示账单完整或价格基数已核验。
- 本期展示费用，不包含 CPU、内存、网络运行指标及用量数量。

## 同步与历史

成功的租户验证、手动订阅同步、每日任务与补充刷新均会为对应日期排入独立资源费用任务。资源权限/采集失败单独显示，不改写订阅正常同步状态。每日/补充调度保持原配置；页面每 15 秒读取最新已落库数据。

升级为现有有效订阅补采本月已完成的 UTC 日期。更早日期通过资源页选择范围并点击“采集所选区间”触发，最多 367 日；不会在升级时追加整年资源请求。源未提供 ResourceId 维度会显示具体采集错误。费用已删除的日期会被永久删除墓碑拦截；整对象删除、历史归属删除和恢复重放包含资源事实、原始快照和覆盖记录。

## 验证

SQLite 和 PostgreSQL 各 47 passed / 1 skipped；覆盖不重复计费、未分配费用、按日修订/幂等、历史归属、删除及恢复、精度、资源任务成功与限流隔离。跳过项为另一个数据库专用恢复场景。浏览器验收脚本 `frontend/e2e-resource-costs.mjs` 仅允许本地演示环境，使用合成费用检查导航、金额、明细、空订阅切换及手机布局。

本地浏览器验收复现（仅合成演示环境）：

```bash
docker exec -i azure-lens-smoke-app-1 python - < backend/tests/resource_browser_fixture.py > /tmp/azurelens-resource-browser-fixture.json
BASE_URL=http://127.0.0.1:8001 node frontend/e2e-resource-costs.mjs
```

种子脚本仅追加带“浏览器验收”名称的合成对象，要求已有专用演示用户；不清空数据库。浏览器脚本拒绝公网 URL。
